# oncall-notes

Shift handover notes, but for the entire tech industry.

I run infra. When a model provider slashes prices, that's a capacity
planning event. When a new agent framework drops, that's an eval on my
weekend. When the Nasdaq tech index rips, my pager is quieter — mostly.

## channel: t.me/Lx_groups

A daily Chinese-language digest that treats AI / chips / open source /
markets like a status board:

- 🟢 **#发布** — new model or tool shipped
- 🟡 **#降价** — pricing change, capacity impact noted
- 🔵 **#芯片** — hardware benchmarks, on-device trends
- ⚪ **#开源** — agent ecosystem, self-hostable tools
- 🔴 **#创新高** — index milestones, watch but don't chase

Every post ships with its source link. Free, no ads, no data collection.

## escalation path

When a digest item is load-bearing enough to warrant more than 3 lines:

1. The channel posts the same day, with the origin link.
2. [blog.lynxflow.co](https://blog.lynxflow.co) publishes the deep dive.
3. [blog.lxlynx.com/tg-channel-landing/](https://blog.lxlynx.com/tg-channel-landing/)
   answers "should I subscribe at all?"

Run this loop before your next shift, not after.
